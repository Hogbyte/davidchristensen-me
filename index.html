Frontend lead for a new compliance data model

Problem

A new compliance feature needed new statuses and new endpoints. The frontend and backend teams had different views of what the UI must read and write.

What I Did

  • Wrote the frontend technical analysis: endpoints, data types, statuses, and a nested feature-flag pattern. Split the work for 2 other engineers.

Testing federated micro-frontends inside a real host

Problem

Our micro-frontends load inside other teams' pages through Module Federation, and nothing tested them there. A dependency upgrade that I merged broke a shared viewer in 3 host products, while the synthetic monitors stayed green, because they checked only that the remote was reachable.

What I Did

  • Explained the failure and the monitor gap, and added a mandatory host check to our dependency-update process.
  • Designed a shared Playwright suite with a remote-override convention, so a test can load a pull-request preview into a real host. It runs in staging and production.
  • Built a CircleCI workflow that runs each service's smoke tests against its preview and posts the result on the pull request. It covers 4 services, including one that another team owns. Wrote a design record for it.

Result

That failure class is now caught before merge and in production.
